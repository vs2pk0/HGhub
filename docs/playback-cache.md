# 播放缓存

播放磁盘缓存默认上限为 256 MiB。已有的上限设置会继续生效。上限可设为 128–4096 MiB，设为 0 会关闭并删除已有播放磁盘缓存。数据存放于应用数据目录下 `playback-cache`，重启后保留。清理缓存也会删除磁盘播放缓存，收藏、历史与登录状态保留。关闭磁盘缓存时，播放器继续使用原有的内存缓冲。

下载分为播放请求和后台缓存两层优先级。同一资源的在途下载可由播放请求接管，其他后台下载会暂停读取。后台最多使用两个下载槽，分别用于后续播放方向的预取和已有不完整文件块的补齐。点播 HLS 的独立分片及字节范围分片沿用清单边界，按清单顺序预取，使用完整 URL 和字节范围区分缓存块。单个缓存块超过 16 MiB 时由播放器按需联网。原生 HLS 对多清晰度清单跟随播放器实际请求的清晰度；直播不预取。已选独立音轨、当前开启的字幕轨、解密密钥和初始化片段纳入同一预取队列；关闭字幕时停止字幕预取；播放中途重新开启时，优先加载当前位置的字幕段，再向后预取，已经播放过的字幕段不补下载，已有字幕块直接复用。切换音轨或字幕语言时取消旧任务并拒绝旧轨道迟到的清单。内嵌音频和字幕随原有媒体块一起缓存。直接媒体按固定 1 MiB 字节块存储，块内以最多 64 KiB 的共享传输记录已收到的范围。播放请求优先获取实际需要的字节，后续预取从已收到数据的末尾继续，不完整块的前半部分可并发补齐。收到的完整传输范围可在再次跳转时复用，收齐整个块后标记为完整缓存。部分块按其完整块大小计入磁盘上限。此功能在上游支持字节范围并提供强 ETag 时启用，ETag 变化后使用新的缓存标识。其他地址沿用播放器原有的网络路径。对于未知扩展名的播放地址，仍按原有 HLS 路径处理。

按当前播放速度折算，连续缓冲至少 5 秒时启动后续预取，至少 10 秒时启动部分块补齐。暂停播放时允许后台缓存，部分块补齐还要求播放器已有足够数据可显示画面。缓冲低于 5 秒或正在跳转时暂停后台读取，当前播放请求仍可接管同一下载。点击进度条或拖动松手后，预取队列立即按跳转位置重排，优先填补前方最近的缓存缺口。空间不足时，缺口之后的分片和已进入当前连续播放缓冲的音视频分片可以按最近最少访问淘汰。无法腾出空间时暂停预取，缓冲推进后重新检查。直接文件从最近一次范围请求的位置开始预取，并随该请求实际返回的字节推进。缓存上限包含已分配的不完整文件块，不包含播放器及 WebView 内存缓冲、尚未落盘的传输数据或其他应用数据。

磁盘缓存关闭时不显示淡色缓存指示；播放器仍保留播放所需的短时内存缓冲，这段缓冲不算作缓存功能。开启后，淡色部分表示已写入磁盘的时间范围，并包含播放器已经缓冲、尚未记入磁盘的部分。直接文件无法可靠地将字节位置换算成播放时间，因此只在磁盘缓存开启时显示播放器报告的缓冲范围。有独立音轨或开启的独立字幕时，磁盘缓存指示取所选音视频、字幕完整区间的交集，并检查所需密钥与初始化片段；亮色部分为播放进度。完整 URL 的哈希作为缓存键，因此上游更换带签名的地址后不一定复用此前缓存。网络流量可能高于实际观看量；系统播放器缓冲和缓存数据不保证离线观看。

关闭、清理、切集或页面失活会取消排队和进行中的预取，恢复页面时重新检查缓存。单个失败资源最多重试三次，不阻挡其他分片；再次跳转、切换清晰度、恢复页面或更改缓存设置可重新尝试。直接文件完成后不再反复扫描整个文件。

清单与视频分片采用不同有效期：已结束点播主清单缓存 5 分钟，其余主清单 2 秒；子清单不进入分片内存缓存，协议层不缓存清单。启用磁盘缓存时分片响应不再由 WebView 单独长期缓存，以便读取更新 LRU 和清理状态。磁盘索引的访问时间和部分块范围在运行中即时更新，索引约每 5 秒合并保存，并在分配块和完成整个块时保存。异常退出后，尚未保存到索引的部分范围可能再次下载。

验证入口：`pnpm test:cache` 覆盖队列、依赖、取消、容量变化和 EOF；`pnpm test:playback --scenarios cache-resume,mp4-cache` 将真实浏览器接入测试 HTTP 桥，验证 Rust 磁盘缓存下的 HLS 续播与 MP4 解码、跳转和复用。运行条件和完整场景见 [播放回归说明](playback-diagnostics.md)。在 `src-tauri` 下运行 `cargo test --offline --locked --lib`，覆盖部分块落盘失败、索引恢复、容量淘汰和共享任务清理；允许回环监听后运行 `cargo test --offline --locked --lib local_server -- --ignored --test-threads=1`，用本地 HTTP 验证双向补齐、已收范围复用、在途下载接管、下载中清理/关闭/缩容、ETag 隔离和动态清单。原生 iOS/macOS 播放仍需实机验证；这些自动测试不等同于原生播放器实测。
